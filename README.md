# stitchurl

Stitch encode/decode helpers for url payloads in pipelines.

**Site:** https://theworker02.github.io/stitchurl/

## Install / run

```bash
git clone https://github.com/theworker02/stitchurl.git
cd stitchurl
node src/cli.js
node --test
```
